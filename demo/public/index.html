Anyone WASM demo

Independent, experimental browser client.

The browser worker verifies the signed Anyone directory and opens a circuit through the local WebSocket bridge. A request to httpbingo.org returns the exit IP.

The bridge sees your connection and the first relay address. The test endpoint receives the exit IP and a random test ID.
